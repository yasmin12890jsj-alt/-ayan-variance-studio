⚖️ قوانين حساب الفروقات المعتمدة
1. الفرق المطلق (Écart absolu):
Ecart_Absolu = Reel - Previsionnel
2. الفرق النسبي (Écart relatif %):
Ecart_Relatif_% = Previsionnel != 0 ? ((Reel - Previsionnel) / |Previsionnel|) * 100 : 0
3. فرق الميزانية (Écart budgétaire):
Ecart_Budget = Budget_Reel - Budget_Previsionnel
4. فرق الكميات (Écart quantité):
Ecart_Quantite = Quantite_Reel - Quantite_Previsionnel
5. فرق الأداء (Écart performance):
Ecart_Performance = Performance_Reel - Objectif
